# O projektu

pgAdmin III je nejoblíbenější open-source nástroj pro administraci a vývoj databází PostgreSQL. Původní projekt byl oficiálně ukončen ve prospěch webového pgAdmin 4, ale tato komunitní větev udržuje nativní wxWidgets aplikaci při životě — opravuje chyby pro moderní verze PostgreSQL a přidává desítky nových funkcí.

Tato verze přináší plně nativní macOS port pro Apple Silicon (arm64), distribuovaný jako samostatný .app bundle přes Homebrew Cask.

# Hlavní funkce

🖥️ Nativní macOS

Skutečná nativní aplikace postavená na wxWidgets 3.3 + Cocoa. Žádný Electron, žádná Java — nízká spotřeba paměti, rychlý start.

🐘 PostgreSQL 12–18

Plná podpora moderních verzí PostgreSQL včetně PostgresPro Enterprise, Slony-I replikace a pgAgent jobů.

🔍 SQL Editor

Syntax highlighting, automatická detekce příkazu pod kurzorem, automatické ukládání záložek, více oken výsledků, PCRE transformace textu.

📊 Nástroj pro dotazy

Pojmenované bookmarky, join autocompletion přes cizí klíče, human-readable velká čísla, diff pohled "porovnej 2 buňky".

🔄 Nástroje schémat

Porovnávání objektů mezi servery s HTML diff reportem, GitLab-backed version control, B-tree checking přes amcheck.

📈 Monitoring

Server Status / Activity okno, zvýraznění procesů, wait-event sampling (pg_wait_sampling), AWR reporty, CSV log viewer.

🎨 SVG toolbar

Moderní SVG ikony, HiDPI / Retina ready, barevné odlišení serverů.

🌐 Lokalizace

45 jazyků, všechny s editovatelnými .po zdroji a kompletním překladem.

🔌 Pluginy

Rozšiřitelnost pomocí zásuvných modulů — přidejte vlastní funkce bez úpravy jádra.

🔐 SSL / SSH

SSL/TLS šifrování a SSH tunely (libssh2) pro bezpečný přístup k serverům.

# Instalace

macOS (Apple Silicon) — nejjednodušší cesta

Prekompilovaná verze přes Homebrew Cask:

brew install heptau/tap/pgadmin3

Po instalaci spustíte z Launchpadu, Spotlightu nebo terminálu:

open /Applications/pgAdmin\ III.app

Sestavení ze zdroje (macOS)

git clone https://github.com/heptau/pgadmin3.git
cd pgadmin3
make build
open "build-macos/pgAdmin III.app"

Poznámka: První build vyžaduje lokálně sestavenou wxWidgets 3.3 (s --disable-std_containers). Homebrew bottle není kompatibilní — viz AGENTS.md.

Linux

git clone https://github.com/heptau/pgadmin3.git
cd pgadmin3
make build
./build/pgAdmin3

Windows

Otevřete pgAdmin3.vcxproj ve Visual Studiu nebo cross-compilujte z Linuxu pomocí mingw — viz INSTALL_EN.txt.

Nebo si stáhněte předkompilovaný přenosný zip ze stránky GitHub releases (pgAdmin3-<version>-windows-x64.zip) — nejsou potřeba žádné build nástroje, stačí rozbalit a spustit pgAdmin3.exe. Poznámka: tento zip je sestaven z binárky upstream forku levinsv/pgadmin3, takže nemusí obsahovat všechny opravy z buildu tohoto projektu pro macOS — ale obsahuje další jazyky a dokumentaci guru-hint udržovanou zde.

# Co je nového

v2026.09.22

  • Vlastnosti serveru zobrazují vybrané parametry postgresql.conf (včetně hodnot čekajících na restart) a štítky serveru
  • Vložení údajů o připojení ve tvaru Klíč=Hodnota ze schránky přímo do dialogu „Nový server“
  • Volitelné zobrazení závislostí funkcí — tabulky, pohledy a funkce, na které odkazují funkce/procedury, na kartě Závislosti
  • Tmavý režim pro Linux/GTK v mřížce výsledků, EXPLAIN plánu a dalších místech, s nastavitelnými barvami
  • Základní podpora pro neprivilegované uživatele PostgreSQL
  • Opravy: parser závislostí plpgsql, identifikátory začínající _, pád JSON stromu, okno rychlého hledání F4

v2026.08.16

  • Volitelný šifrovaný systémový trezor pro uložená hesla k serverům
  • Integrace s far2l (přes NetRocks)
  • Přenosný zip pro Windows u každého vydání na GitHubu

v2026.08.07

  • Export do souboru ve formátu PostgreSQL COPY
  • Porovnání po řádcích v dialogu porovnání, přehlednější diff reporty
  • Opraveno Alt+E v mřížce výsledků a pád při opakovaném spuštění běžícího dotazu

v2026.07.21 a starší

  • Všech 45 jazyků dokončeno, s editovatelnými .po zdroji
  • Dokumentace guru tipů v 18 jazycích
  • Nativní macOS build (arm64) přes Homebrew Cask, živé přepínání tmavého / světlého režimu, Retina ikony
  • Podpora PostgreSQL 18
