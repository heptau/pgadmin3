# À propos

pgAdmin III est la plateforme open-source la plus populaire pour l'administration et le développement de PostgreSQL. Le projet original a été retiré au profit de pgAdmin 4 basé sur le web, mais ce fork communautaire maintient l'application native wxWidgets en vie — corrigeant les bogues pour les versions modernes de PostgreSQL et ajoutant des dizaines de nouvelles fonctionnalités.

Cette version introduit un port macOS entièrement natif pour Apple Silicon (arm64), distribué sous forme de bundle .app autonome via Homebrew Cask.

# Fonctionnalités principales

🖥️ macOS natif

Une véritable application native construite avec wxWidgets 3.3 + Cocoa. Pas d'Electron, pas de Java — faible empreinte mémoire, démarrage rapide.

🐘 PostgreSQL 12–18

Prise en charge complète des versions modernes de PostgreSQL, de PostgresPro Enterprise, de la réplication Slony-I et de la planification pgAgent.

🔍 Éditeur SQL

Coloration syntaxique, détection automatique de l'instruction sous le curseur, onglets sauvegardés automatiquement, multiples fenêtres de résultats, transformations de texte avec PCRE.

📊 Outil de requêtes

Signets nommés, saisie semi-automatique des jointures via les clés étrangères, grands nombres lisibles, vue de différences par comparaison de cellules.

🔄 Outils de schéma

Comparaison d'objets entre serveurs avec rapports de différences HTML, contrôle de version via GitLab, vérification d'index B-tree via amcheck.

📈 Surveillance

Fenêtre d'état/activité du serveur, surlignage des processus, échantillonnage des événements d'attente (pg_wait_sampling), rapports AWR, visualisateur de journaux CSV.

🎨 Barre d'outils SVG

Icônes modernes de barre d'outils en SVG, prêtes pour HiDPI/Retina, code couleur par serveur.

🌐 Localisation

45 langues fournies, toutes avec des sources .po modifiables et des traductions complètes.

🔌 Extensions

Extensible via des modules d'extension — ajoutez des fonctionnalités personnalisées sans modifier le noyau.

🔐 SSL / SSH

Chiffrement de connexion SSL/TLS et tunneling SSH (libssh2) pour un accès sécurisé au serveur.

# Installation

macOS (Apple Silicon) — chemin le plus rapide

Binaire précompilé via Homebrew Cask :

brew install heptau/tap/pgadmin3

Lancez depuis Launchpad, Spotlight ou le terminal :

open /Applications/pgAdmin\ III.app

Compiler depuis les sources (macOS)

git clone https://github.com/heptau/pgadmin3.git
cd pgadmin3
make build
open "build-macos/pgAdmin III.app"

Remarque : La première compilation nécessite wxWidgets 3.3 compilé localement (avec --disable-std_containers). La bouteille Homebrew n'est pas compatible — voir AGENTS.md pour plus de détails.

Linux

git clone https://github.com/heptau/pgadmin3.git
cd pgadmin3
make build
./build/pgAdmin3

Windows

Ouvrez pgAdmin3.vcxproj dans Visual Studio, ou compilez croisé depuis Linux avec mingw — voir INSTALL_EN.txt.

Ou récupérez le zip portable précompilé depuis la page GitHub releases (pgAdmin3-<version>-windows-x64.zip) — aucun outil de compilation nécessaire, il suffit de décompresser et de lancer pgAdmin3.exe. Remarque : ce zip est compilé à partir du binaire du fork amont levinsv/pgadmin3, il peut donc ne pas inclure tous les correctifs de la compilation macOS de ce projet — mais il inclut les langues supplémentaires et la documentation des astuces gourou maintenue ici.

# Nouveautés

v2026.09.22

  • Les propriétés du serveur affichent des paramètres choisis de postgresql.conf (y compris les valeurs en attente de redémarrage) et les étiquettes du serveur
  • Collez les informations de connexion Clé=Valeur du presse-papiers directement dans la boîte de dialogue « Nouveau serveur »
  • Vue optionnelle des dépendances des fonctions — tables, vues et fonctions référencées par les fonctions/procédures dans l'onglet Dépendances
  • Mode sombre sous Linux/GTK pour la grille de résultats, le plan EXPLAIN et plus, avec des couleurs configurables
  • Prise en charge de base des utilisateurs PostgreSQL non privilégiés
  • Corrections : analyseur de dépendances plpgsql, identifiants commençant par _, plantage de l'arbre JSON, fenêtre de recherche rapide F4

v2026.08.16

  • Coffre-fort chiffré optionnel du système pour les mots de passe enregistrés des serveurs
  • Intégration avec far2l (via NetRocks)
