# Über

pgAdmin III ist die beliebteste Open-Source-Verwaltungs- und Entwicklungsplattform für PostgreSQL. Das ursprüngliche Projekt wurde zugunsten des webbasierten pgAdmin 4 eingestellt, aber dieser Community-Fork hält die native wxWidgets-Anwendung am Leben — behebt Fehler für moderne PostgreSQL-Versionen und fügt Dutzende neuer Funktionen hinzu.

Diese Version führt einen vollständig nativen macOS-Port für Apple Silicon (arm64) ein, verteilt als eigenständiges .app-Bundle über Homebrew Cask.

  • Upstream-Fork: levinsv/pgadmin3 (PostgreSQL 18-Unterstützung)

# Hauptfunktionen

🖥️ Natives macOS

Eine echte native App basierend auf wxWidgets 3.3 + Cocoa. Kein Electron, kein Java — geringer Speicherverbrauch, schneller Start.

🐘 PostgreSQL 12–18

Volle Unterstützung für moderne PostgreSQL-Versionen, PostgresPro Enterprise, Slony-I-Replikation und pgAgent-Planung.

🔍 SQL-Editor

Syntaxhervorhebung, automatische Erkennung der Anweisung unter dem Cursor, automatisch gespeicherte Tabs, mehrere Ergebnisfenster, PCRE-Texttransformationen.

📊 Abfragetool

Benannte Lesezeichen, Join-Autovervollständigung über Fremdschlüssel, menschenlesbare große Zahlen, Zellvergleichs-Diff-Ansicht.

🔄 Schema-Tools

Serverübergreifender Objektvergleich mit HTML-Diff-Berichten, GitLab-gestützter Versionsverwaltung, B-Tree-Indexprüfung via amcheck.

📈 Überwachung

Serverstatus-/Aktivitätsfenster, Prozesshervorhebung, Warte-Ereignis-Abtastung (pg_wait_sampling), AWR-Berichte, CSV-Protokollbetrachter.

🎨 SVG-Symbolleiste

Moderne SVG-Symbolleistensymbole, HiDPI-/Retina-bereit, Farbcodierung pro Server.

🌐 Lokalisierung

45 Sprachen werden ausgeliefert, alle mit bearbeitbaren .po-Quellen und vollständigen Übersetzungen.

🔌 Erweiterungen

Erweiterbar über Plug-in-Module — fügen Sie benutzerdefinierte Funktionen hinzu, ohne den Kern zu ändern.

🔐 SSL / SSH

SSL/TLS-Verbindungsverschlüsselung und SSH-Tunneling (libssh2) für sicheren Serverzugriff.

# Installation

macOS (Apple Silicon) — schnellster Weg

Vorgefertigte Binärdatei über Homebrew Cask:

brew install heptau/tap/pgadmin3

Starten Sie über Launchpad, Spotlight oder das Terminal:

open /Applications/pgAdmin\ III.app

Aus dem Quellcode erstellen (macOS)

git clone https://github.com/heptau/pgadmin3.git
cd pgadmin3
make build
open "build-macos/pgAdmin III.app"

Hinweis: Der erste Build benötigt eine lokal kompilierte wxWidgets 3.3 (mit --disable-std_containers). Das Homebrew-Flasche ist nicht kompatibel — siehe AGENTS.md für Details.

Linux

git clone https://github.com/heptau/pgadmin3.git
cd pgadmin3
make build
./build/pgAdmin3

Windows

Öffnen Sie pgAdmin3.vcxproj in Visual Studio, oder cross-compilieren Sie von Linux mit mingw — siehe INSTALL_EN.txt.

Oder laden Sie das vorgefertigte portable ZIP von der Seite GitHub releases herunter (pgAdmin3-<version>-windows-x64.zip) — keine Build-Tools nötig, einfach entpacken und pgAdmin3.exe ausführen. Hinweis: Dieses ZIP wird aus der Binärdatei des Upstream-Forks levinsv/pgadmin3 erstellt und enthält daher möglicherweise nicht jeden Fix aus dem macOS-Build dieses Projekts — es enthält jedoch die zusätzlichen Sprachen und die hier gepflegte Guru-Hint-Dokumentation.
