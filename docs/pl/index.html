# O projekcie

pgAdmin III to najpopularniejsza platforma administracyjna i programistyczna open-source dla PostgreSQL. Oryginalny projekt został wycofany na rzecz webowego pgAdmin 4, ale ten fork społecznościowy utrzymuje przy życiu natywną aplikację wxWidgets — naprawia błędy dla nowoczesnych wersji PostgreSQL i dodaje dziesiątki nowych funkcji.

Ta wersja wprowadza w pełni natywny port macOS dla Apple Silicon (arm64), dystrybuowany jako samodzielny pakiet .app przez Homebrew Cask.

# Kluczowe funkcje

🖥️ Natywny macOS

W pełni natywna aplikacja zbudowana na wxWidgets 3.3 + Cocoa. Bez Electrona, bez Javy — niskie zużycie pamięci, szybki start.

🐘 PostgreSQL 12–18

Pełne wsparcie dla nowoczesnych wersji PostgreSQL, PostgresPro Enterprise, replikacji Slony-I i harmonogramu pgAgent.

🔍 Edytor SQL

Podświetlanie składni, automatyczne wykrywanie instrukcji pod kursorem, automatycznie zapisywane karty, wiele okien wyników, transformacje tekstu PCRE.

📊 Narzędzie zapytań

Nazwane zakładki, autouzupełnianie JOIN przez klucze obce, czytelne dla człowieka duże liczby, widok porównania komórek diff.

🔄 Narzędzia schematów

Porównywanie obiektów między serwerami z raportami diff w HTML, kontrola wersji przez GitLab, sprawdzanie indeksów B-tree przez amcheck.

📈 Monitorowanie

Okno statusu/aktywności serwera, podświetlanie procesów, próbkowanie wait-event (pg_wait_sampling), raporty AWR, przeglądarka logów CSV.

🎨 Pasek narzędzi SVG

Nowoczesne ikony paska narzędzi w SVG, gotowość dla HiDPI / Retina, kodowanie kolorami dla każdego serwera.

🌐 Lokalizacja

45 języków w dystrybucji, wszystkie z edytowalnymi źródłami .po i kompletnymi tłumaczeniami.

🔌 Wtyczki

Rozszerzalny poprzez moduły wtyczek — dodawaj własne funkcje bez modyfikacji rdzenia.

🔐 SSL / SSH

Szyfrowanie połączeń SSL/TLS i tunelowanie SSH (libssh2) dla bezpiecznego dostępu do serwera.

# Instalacja

macOS (Apple Silicon) — najszybsza ścieżka

Gotowy plik binarny przez Homebrew Cask:

brew install heptau/tap/pgadmin3

Uruchom z Launchpad, Spotlight lub terminala:

open /Applications/pgAdmin\ III.app

Kompilacja z źródeł (macOS)

git clone https://github.com/heptau/pgadmin3.git
cd pgadmin3
make build
open "build-macos/pgAdmin III.app"

Uwaga: Pierwsza kompilacja wymaga lokalnie skompilowanej wxWidgets 3.3 (z --disable-std_containers). Butelka Homebrew nie jest kompatybilna — szczegóły w AGENTS.md.

Linux

git clone https://github.com/heptau/pgadmin3.git
cd pgadmin3
make build
./build/pgAdmin3

Windows

Otwórz pgAdmin3.vcxproj w Visual Studio lub wykonaj cross-kompilację z Linuksa przy użyciu mingw — zobacz INSTALL_EN.txt.

Lub pobierz gotowy przenośny plik zip ze strony GitHub releases (pgAdmin3-<version>-windows-x64.zip) — nie są potrzebne żadne narzędzia do kompilacji, wystarczy rozpakować i uruchomić pgAdmin3.exe. Uwaga: ten plik zip jest zbudowany z binarki forka levinsv/pgadmin3, więc może nie zawierać wszystkich poprawek z kompilacji macOS tego projektu — zawiera jednak dodatkowe języki i dokumentację guru-hint utrzymywaną w tym projekcie.

# Co nowego

v2026.09.22

  • Właściwości serwera pokazują wybrane parametry postgresql.conf (w tym wartości oczekujące na restart) oraz tagi serwera
  • Wklejanie danych połączenia w formacie Klucz=Wartość ze schowka bezpośrednio do okna „Nowy serwer”
  • Opcjonalny widok zależności funkcji — tabele, widoki i funkcje, do których odwołują się funkcje/procedury, na karcie Zależności
  • Tryb ciemny w Linux/GTK dla siatki wyników, planu EXPLAIN i innych, z konfigurowalnymi kolorami
  • Podstawowa obsługa nieuprzywilejowanych użytkowników PostgreSQL
  • Poprawki: parser zależności plpgsql, identyfikatory zaczynające się od _, awaria drzewa JSON, okno szybkiego wyszukiwania F4

v2026.08.16

  • Opcjonalny szyfrowany magazyn poświadczeń systemu dla zapisanych haseł serwerów
  • Integracja z far2l (przez NetRocks)
