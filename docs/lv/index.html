Instalēt, izmantojot Homebrew Pirmkods

# Par

pgAdmin III ir vispopulārākā atvērtā pirmkoda PostgreSQL administrēšanas un izstrādes platforma. Sākotnējais projekts tika pārtraukts par labu tīmekļa bāzes pgAdmin 4, bet šis kopienas atzarojums uztur dzīvu vietējo wxWidgets lietotni — labo kļūdas modernām PostgreSQL versijām un pievieno desmitiem jaunu iespēju.

Šis izlaidums ievieš pilnīgi vietējo macOS portu Apple Silicon (arm64), izplatītu kā pašpietiekamu .app komplektu, izmantojot Homebrew Cask.

# Galvenās iespējas

🖥️ Vietējais macOS

Īsti vietējā lietotne, kas būvēta uz wxWidgets 3.3 + Cocoa. Nav Electron, nav Java — zema atmiņas noslodze, ātra palaišana.

🐘 PostgreSQL 12–18

Pilns atbalsts modernām PostgreSQL versijām, PostgresPro Enterprise, Slony-I replikācijai un pgAgent plānošanai.

🔍 SQL redaktors

Sintakses izcelšana, automātiska paziņojuma noteikšana zem kursora, automātiski saglabātas cilnes, vairāki rezultātu logi, PCRE teksta transformācijas.

📊 Vaicājumu rīks

Nosauktas grāmatzīmes, savienojumu automātiskā pabeigšana, izmantojot ārējās atslēgas, cilvēkiem lasāmi lieli skaitļi, šūnu salīdzināšanas diff skats.

🔄 Shēmas rīki

Starp-serveru objektu salīdzināšana ar HTML diff pārskatiem, GitLab balstīta versiju kontrole, B-koka indeksu pārbaude, izmantojot amcheck.

📈 Uzraudzība

Servera statusa / aktivitātes logs, procesu izcelšana, gaidīšanas notikumu paraugu ņemšana (pg_wait_sampling), AWR pārskati, CSV žurnālu skatītājs.

🎨 SVG rīkjosla

Modernas SVG rīkjoslas ikonas, gatavas HiDPI / Retina, krāsu kodējums katram serverim.

🌐 Lokalizācija

45 valodas iekļautas, visas ar rediģējamiem .po avotiem un pilnīgiem tulkojumiem.

🔌 Spraudņi

Paplašināms, izmantojot spraudņu moduļus — pievienojiet pielāgotu funkcionalitāti, nemainot kodolu.

🔐 SSL / SSH

SSL/TLS savienojuma šifrēšana un SSH tunelēšana (libssh2) drošai servera piekļuvei.

# Instalēšana

macOS (Apple Silicon) — ātrākais ceļš

Iepriekš būvēta binārā datne, izmantojot Homebrew Cask:

brew install heptau/tap/pgadmin3

Palaist no Launchpad, Spotlight vai termināļa:

open /Applications/pgAdmin\ III.app

Būvēt no pirmkoda (macOS)

git clone https://github.com/heptau/pgadmin3.git
cd pgadmin3
make build
open "build-macos/pgAdmin III.app"

Piezīme: Pirmā būvēšana prasa lokāli kompilētu wxWidgets 3.3 (ar --disable-std_containers). Homebrew pudele nav saderīga — skatiet AGENTS.md, lai uzzinātu sīkāk.

Linux

git clone https://github.com/heptau/pgadmin3.git
cd pgadmin3
make build
./build/pgAdmin3

Windows

Atveriet pgAdmin3.vcxproj programmā Visual Studio vai veiciet krustenisko kompilāciju no Linux ar mingw — skatiet INSTALL_EN.txt.

Vai lejupielādējiet iepriekš būvēto pārnēsājamo zip no GitHub releases lapas (pgAdmin3-<version>-windows-x64.zip) — nav vajadzīgi nekādi būvēšanas rīki, vienkārši atarhivējiet un palaidiet pgAdmin3.exe. Piezīme: šis zip ir būvēts no upstream levinsv/pgadmin3 atzara binārā faila, tāpēc tajā var nebūt visu šī projekta macOS būvējuma labojumu — taču tas ietver papildu valodas un šeit uzturēto guru-hint dokumentāciju.
