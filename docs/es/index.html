# Acerca de

pgAdmin III es la plataforma de código abierto más popular para la administración y el desarrollo de PostgreSQL. El proyecto original fue retirado en favor de pgAdmin 4 basado en web, pero este fork comunitario mantiene viva la aplicación nativa wxWidgets: corrige errores para versiones modernas de PostgreSQL y añade docenas de funciones nuevas.

Esta versión presenta un puerto nativo completo para macOS para Apple Silicon (arm64), distribuido como un paquete .app autónomo mediante Homebrew Cask.

  • Repositorio: github.com/heptau/pgadmin3
  • Fork upstream: levinsv/pgadmin3 (Compatibilidad con PostgreSQL 18)
  • Proyecto original: postgres/pgadmin3 (archived)

# Características principales

🖥️ macOS nativo

Una auténtica aplicación nativa construida sobre wxWidgets 3.3 + Cocoa. Sin Electron, sin Java — bajo consumo de memoria, inicio rápido.

🐘 PostgreSQL 12–18

Compatibilidad total con versiones modernas de PostgreSQL, PostgresPro Enterprise, replicación Slony-I y planificación de pgAgent.

🔍 Editor SQL

Resaltado de sintaxis, detección automática de la sentencia bajo el cursor, pestañas con guardado automático, múltiples ventanas de resultados, transformaciones de texto con PCRE.

📊 Herramienta de consultas

Marcadores con nombre, autocompletado de combinaciones mediante claves ajenas, números grandes legibles, vista de diferencias por comparación de celdas.

🔄 Herramientas de esquemas

Comparación de objetos entre servidores con informes de diferencias HTML, control de versiones con GitLab, comprobación de índices B-tree mediante amcheck.

📈 Monitorización

Ventana de estado/actividad del servidor, resaltado de procesos, muestreo de eventos de espera (pg_wait_sampling), informes AWR, visor de registros CSV.

🎨 Barra de herramientas SVG

Iconos modernos de barra de herramientas en SVG, preparados para HiDPI/Retina, codificación de colores por servidor.

🌐 Localización

Se incluyen 45 idiomas, todos con fuentes .po editables y traducciones completas.

🔌 Complementos

Extensible mediante módulos complementarios — añada funcionalidad personalizada sin modificar el núcleo.

🔐 SSL / SSH

Cifrado de conexión SSL/TLS y tunelización SSH (libssh2) para acceso seguro al servidor.

# Instalación

macOS (Apple Silicon) — vía más rápida

Binario precompilado mediante Homebrew Cask:

brew install heptau/tap/pgadmin3

Inicie desde Launchpad, Spotlight o el terminal:

open /Applications/pgAdmin\ III.app

Compilar desde el código fuente (macOS)

git clone https://github.com/heptau/pgadmin3.git
cd pgadmin3
make build
open "build-macos/pgAdmin III.app"

Nota: La primera compilación requiere wxWidgets 3.3 compilado localmente (con --disable-std_containers). El bottle de Homebrew no es compatible — consulte AGENTS.md para más detalles.

Linux

git clone https://github.com/heptau/pgadmin3.git
cd pgadmin3
make build
./build/pgAdmin3

Windows

Abra pgAdmin3.vcxproj en Visual Studio, o compile de forma cruzada desde Linux con mingw — consulte INSTALL_EN.txt.

O descargue el zip portátil precompilado desde la página de GitHub releases (pgAdmin3-<version>-windows-x64.zip) — no se necesitan herramientas de compilación, simplemente descomprima y ejecute pgAdmin3.exe. Nota: este zip está compilado a partir del binario del fork levinsv/pgadmin3, por lo que puede que no incluya todas las correcciones de la compilación de macOS de este proyecto — pero sí incluye los idiomas adicionales y la documentación de sugerencias gurú mantenida aquí.

# Novedades

v2026.09.22

  • Las propiedades del servidor muestran parámetros seleccionados de postgresql.conf (incluidos los valores pendientes de reinicio) y las etiquetas del servidor
  • Pegue la información de conexión Clave=Valor del portapapeles directamente en el diálogo «Nuevo servidor»
  • Vista opcional de dependencias de funciones — tablas, vistas y funciones referenciadas por funciones/procedimientos en la pestaña Dependencias
  • Modo oscuro en Linux/GTK para la cuadrícula de resultados, el plan EXPLAIN y más, con colores configurables
  • Soporte básico para usuarios de PostgreSQL sin privilegios
  • Correcciones: analizador de dependencias plpgsql, identificadores que empiezan por _, cierre inesperado del árbol JSON, ventana de búsqueda rápida F4

v2026.08.16

  • Almacén cifrado opcional del sistema para las contraseñas guardadas de los servidores
  • Integración con far2l (vía NetRocks)
  • Zip portable para Windows publicado con cada versión en GitHub

v2026.08.07

  • Exportación a archivo en formato PostgreSQL COPY
  • Comparación línea a línea en el diálogo de comparación, informes de diferencias más claros
  • Corregido Alt+E en la cuadrícula de resultados y un cierre inesperado al volver a ejecutar una consulta en curso

v2026.07.21 y anteriores

  • Los 45 idiomas completados, con fuentes .po editables
  • Documentación de consejos guru en 18 idiomas
  • Compilación nativa para macOS (arm64) vía Homebrew Cask, modo oscuro / claro en vivo, iconos Retina
