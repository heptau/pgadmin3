# О програму

pgAdmin III је најпопуларнија платформа отвореног кода за администрирање и развој PostgreSQL-а. Оригинални пројекат је повучен у корист веб-базираног pgAdmin 4, али овај форк заједнице одржава изворну wxWidgets апликацију живом — исправља грешке за модерне верзије PostgreSQL-а и додаје десетине нових функција.

Ово издање представља потпуно изворни macOS порт за Apple Silicon (arm64), дистрибуиран као самостални .app пакет путем Homebrew Cask-а.

# Кључне функције

🖥️ Изворни macOS

Права изворна апликација изграђена на wxWidgets 3.3 + Cocoa. Без Electron-а, без Java-е — мали меморијски отисак, брзо покретање.

🐘 PostgreSQL 12–18

Потпуна подршка за модерне PostgreSQL верзије, PostgresPro Enterprise, Slony-I репликацију и pgAgent распоређивање.

🔍 SQL едитор

Истицање синтаксе, аутоматско откривање израза испод курсора, аутоматски сачуване картице, више прозора са резултатима, PCRE трансформације текста.

📊 Алат за упите

Именоване маркице, аутоматско довршавање спајања преко страних кључева, људски читљиви велики бројеви, приказ diff поређења ћелија.

🔄 Алати за шему

Поређење објеката између сервера са HTML diff извештајима, GitLab вођење верзија, провера B-tree индекса путем amcheck.

📈 Надгледање

Прозор статуса / активности сервера, истицање процеса, узорковање догађаја чекања (pg_wait_sampling), AWR извештаји, CSV прегледач дневника.

🎨 SVG алатна трака

Модерне SVG иконе алатне траке, спремне за HiDPI / Retina, кодирање боја по серверу.

🌐 Локализација

45 језика укључено, сви са уредивим .po изворима и потпуним преводима.

🔌 Додаци

Проширив преко модула додатака — додајте прилагођену функционалност без измене језгра.

🔐 SSL / SSH

SSL/TLS шифровање везе и SSH тунелирање (libssh2) за безбедан приступ серверу.

# Инсталација

macOS (Apple Silicon) — најбржи пут

Унапред изграђени бинарни фајл путем Homebrew Cask:

brew install heptau/tap/pgadmin3

Покрените из Launchpad, Spotlight или терминала:

open /Applications/pgAdmin\ III.app

Изградња из изворног кода (macOS)

git clone https://github.com/heptau/pgadmin3.git
cd pgadmin3
make build
open "build-macos/pgAdmin III.app"

Напомена: Прва изградња захтева локално компајлирану wxWidgets 3.3 (са --disable-std_containers). Homebrew боца није компатибилна — погледајте AGENTS.md за детаље.

Linux

git clone https://github.com/heptau/pgadmin3.git
cd pgadmin3
make build
./build/pgAdmin3

Windows

Отворите pgAdmin3.vcxproj у Visual Studio-у или урадите унакрсно компајлирање из Linux-а са mingw-ом — погледајте INSTALL_EN.txt.

Или преузмите унапред изграђени преносиви zip са странице GitHub releases (pgAdmin3-<version>-windows-x64.zip) — нису потребни алати за компилацију, само распакујте и покрените pgAdmin3.exe. Напомена: овај zip је изграђен из бинарног фајла upstream levinsv/pgadmin3 огранка, тако да можда не садржи све исправке из macOS изградње овог пројекта — али садржи додатне језике и guru-hint документацију која се овде одржава.
