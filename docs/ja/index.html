# 概要

pgAdmin IIIは、PostgreSQL向けの最も人気のあるオープンソース管理・開発プラットフォームです。元のプロジェクトはWebベースのpgAdmin 4に移行して廃止されましたが、このコミュニティフォークがネイティブwxWidgetsアプリケーションを維持しています。最新のPostgreSQLバージョンへのバグ修正と、数多くの新機能を追加しています。

このリリースでは、Apple Silicon（arm64）向けの完全ネイティブmacOSポートを導入し、Homebrew Cask経由で自己完結型の.appバンドルとして配布します。

  • License: PostgreSQLライセンス（寛容なBSD系ライセンス）
  • リポジトリ: github.com/heptau/pgadmin3
  • アップストリームフォーク: levinsv/pgadmin3 (PostgreSQL 18対応)
  • オリジナルプロジェクト: postgres/pgadmin3 (archived)

# スクリーンショット

# 主な機能

🖥️ ネイティブmacOS

wxWidgets 3.3 + Cocoaで構築された真のネイティブアプリです。ElectronもJavaも使用せず、メモリ使用量が少なく、起動も高速です。

🐘 PostgreSQL 12–18

最新のPostgreSQLバージョン、PostgresPro Enterprise、Slony-Iレプリケーション、pgAgentスケジューリングを完全サポートします。

🔍 SQLエディタ

シンタックスハイライト、カーソル位置のステートメント自動検出、自動保存タブ、複数の結果ウィンドウ、PCREテキスト変換に対応しています。

📊 クエリツール

名前付きブックマーク、外部キーによる結合の自動補完、可読性の高い大きな数値表示、セル比較の差分ビューを備えています。

🔄 スキーマツール

サーバー間のオブジェクト比較とHTML差分レポート、GitLab対応のバージョン管理、amcheckによるB-treeインデックスチェックを提供します。

📈 モニタリング

サーバーステータス/アクティビティウィンドウ、プロセスのハイライト表示、待機イベントサンプリング（pg_wait_sampling）、AWRレポート、CSVログビューアーを備えています。

🎨 SVGツールバー

モダンなSVGツールバーアイコン、HiDPI/Retina対応、サーバーごとの色分け表示をサポートします。

🌐 ローカライゼーション

45言語を同梱し、すべて編集可能な.poソースと完全な翻訳を提供しています。

🔌 プラグイン

プラグインモジュールによる拡張が可能です。コアを変更せずにカスタム機能を追加できます。

🔐 SSL / SSH

SSL/TLS接続暗号化とSSHトンネリング（libssh2）により、安全なサーバーアクセスを実現します。

# インストール

macOS（Apple Silicon）— 最短の方法

Homebrew Cask経由のプリビルドバイナリ：

brew install heptau/tap/pgadmin3

Launchpad、Spotlight、またはターミナルから起動します：

open /Applications/pgAdmin\ III.app

ソースからビルド（macOS）

git clone https://github.com/heptau/pgadmin3.git
cd pgadmin3
make build
open "build-macos/pgAdmin III.app"

注意： 初回ビルドには、ローカルでコンパイルしたwxWidgets 3.3（--disable-std_containers付き）が必要です。Homebrewのボトルは互換性がありません。詳細はAGENTS.mdを参照してください。

Linux

git clone https://github.com/heptau/pgadmin3.git
cd pgadmin3
make build
./build/pgAdmin3

Windows

Visual StudioでpgAdmin3.vcxprojを開くか、Linuxからmingwでクロスコンパイルしてください。詳細はINSTALL_EN.txtを参照してください。

またはGitHubのリリースページからビルド済みのポータブルZIP（pgAdmin3-<version>-windows-x64.zip）を入手してください——ビルドツールは不要で、解凍してpgAdmin3.exeを実行するだけです。注意：このZIPはアップストリームのlevinsv/pgadmin3フォークのバイナリからビルドされているため、本プロジェクトのmacOSビルドのすべての修正が含まれているとは限りませんが、ここで管理されている追加言語とguru-hintドキュメントは含まれています。
